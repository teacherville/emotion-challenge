# 표정 챌린지 (v1.0)

상황 카드 속 마음을 **표정으로 연기**하고, **감정 단어**를 고른 뒤, **이야기 카드**로 함께 이야기 나누는 초등 사회정서 학급놀이 웹앱입니다.

- 서버 없음 · 로그인 없음 · 설치 없음
- 카메라 영상과 얼굴 정보는 **기기 안에서만** 처리되고 어디에도 저장·전송되지 않아요
- 전자칠판 · 노트북 · 아이패드(가로/세로) · 스마트폰 지원
- © 2026 티처빌연수원

## 파일 구성

| 파일 | 하는 일 | 고칠 일이 있을 때 |
| --- | --- | --- |
| `index.html` | 모든 화면의 뼈대 | 버튼 이름, 안내 문구 |

| `cards.js` | **기본 상황 카드 24장, 감정 단어, 이야기 질문, 선생님 팁** | **카드 내용 수정은 이 파일만** |

| `THIRD_PARTY_NOTICES.md` | 오픈소스 라이선스 고지 | 라이브러리를 추가하면 여기도 추가 |
| `.nojekyll` | GitHub Pages 설정용 빈 파일 (지우지 마세요) | |

## 화면 흐름

1. **표지** → 시작하기 / 카드·질문 목록(선생님용) / QR로 폰·태블릿에서 열기
2. **카메라 준비** → 편안한 얼굴 3초 기억(보정). 카메라가 없으면 "카메라 없이 하기"(선생님이 통과 판정)
3. **표정 연기** → 상황 카드의 표정을 지으면 게이지가 차고, 통과선을 넘기면 "우리 반 별" +1
4. **마음 고르기** → 감정 단어 고르기, "+ 다른 마음"으로 새 단어 추가(우리 반 마음 사전에 저장)
5. **이야기 나눠요**(선택) → 자기 · 관계 · 공동체 · 마음건강 질문 4개
6. **완성 화면** → 모은 별과 찾은 마음 단어

## 수정하는 방법

### 카드 내용 바꾸기
- **이 기기에서만** 바꾸려면: 앱의 **카드·질문 목록**에서 고치면 자동 저장돼요.
- **모든 선생님에게** 바꾸려면: `cards.js`를 고쳐서 GitHub에 다시 올려요.
  - 이미 앱을 쓴 기기는 그 기기에 저장된 카드가 먼저 보여요. 새로 추가한 기본 카드(새 `id`)는 자동으로 들어가요.

### 표정 판정이 너무 어렵거나 쉬울 때
- 선생님 화면의 **표정 통과 기준**(쉬움/보통/어려움)으로 먼저 조절해요.
- 전체 기본값을 바꾸려면 `app.js` 위쪽 `TUNING`의 `scale` 숫자를 바꿔요. 숫자가 작을수록 쉬워져요.
  (슬픔·화남 표정은 얼굴 근육 변화가 작아서 기쁨·놀람보다 낮게 잡혀 있어요.)

### Claude(또는 다른 담당자)에게 수정을 맡길 때
이 README와 함께 파일 전체를 주고 "README 읽고 ○○ 고쳐줘"라고 요청하면 돼요.

## 배포 (GitHub Pages)

1. GitHub에서 **New repository** → 이름 입력(예: `emotion-challenge`) → **Public** → Create
2. **uploading an existing file** → 이 폴더 안의 파일과 `assets` 폴더를 전부 끌어다 놓기 → **Commit changes**
3. 저장소 **Settings → Pages** → Source: **Deploy from a branch** → Branch: **main** / **(root)** → Save
4. 1~2분 뒤 `https://<계정이름>.github.io/emotion-challenge/` 주소가 생겨요
5. 이후 파일을 고쳐서 다시 올리면 자동으로 다시 배포돼요

> 카메라는 보안 때문에 **https 주소**에서만 켜져요. GitHub Pages는 기본이 https라 그대로 쓰면 돼요.

## 테스트

- **테스트 모드:** 주소 끝에 `?demo=1`을 붙이면 카메라 없이 점수가 저절로 올라가서 화면 흐름을 확인할 수 있어요.
- **폰으로 확인:** 표지 아래 **폰·태블릿으로 열기 (QR)** → 폰 카메라로 찍기
- **현장 점검 목록**
  - [ ] 전자칠판에 카메라가 있는지(없으면 USB 웹캠)
  - [ ] 전자칠판 브라우저가 최신 크롬인지
  - [ ] 아이패드 사파리에서 카메라 권한 허용
  - [ ] 교실 조명(역광·어두운 곳)에서 얼굴 인식
  - [ ] 표정별 통과 난이도(특히 슬픔·화남)
